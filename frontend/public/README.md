# Static Assets Folder

Put static assets (like logos, images, icons, etc.) that you want to be served directly from the root URL here.

For example:
- Anglican Church Logo -> `frontend/public/anglican-logo.png`
- Hospital Logo -> `frontend/public/hospital-logo.png`

You can then display them in HTML/React using:
`<img src="/anglican-logo.png" alt="Anglican Church Logo" />`
`<img src="/hospital-logo.png" alt="Faith Foundation Mission Hospital Logo" />`
